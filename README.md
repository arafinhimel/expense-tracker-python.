# Personal Expense Tracker

A beginner-level Python console program for keeping track of daily spending. Users can record expenses, view them, search them, and see how much they have spent in total and by category.

## Features
- Add a new expense (date, category, description, amount)
- Show all recorded expenses
- Show total spending
- Show spending by category
- Search expenses by category or description
- Saves expenses to a text file, so records remain after the program is closed
- Handles invalid input, such as letters typed as an amount

## Python concepts used
- Functions
- Lists and dictionaries
- Loops and conditional statements (if / elif / else)
- File handling (reading and writing a text file)
- Basic error handling (try / except)

## How to run
1. Install Python 3
2. Download expense_tracker.py
3. Open a terminal in the same folder and run:

   python3 expense_tracker.py

4. Choose an option from the menu (1-6)

Expenses are saved in a file called expenses.txt, which the program creates automatically in the same folder on first use.

## Menu options
1. Add Expense
2. Show All Expenses
3. Show Total Spending
4. Show Spending by Category
5. Search Expenses
6. Exit
